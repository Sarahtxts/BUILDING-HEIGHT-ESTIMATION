# BUILDING-HEIGHT-ESTIMATION
This is a mini project that involved the use of deep learning library called opencv to detect the height of a building through image recognition and object identification. 
Input: The user inputs an image of a building along with the height of a reference like a tree or a door.
Algorithm: opencv detects the height of the building and the door in pixels and covert it into metres.
Output: The program outputs the height of the building in metres.
